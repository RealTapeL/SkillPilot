# @realtapel/skillpilot-openclaw

> OpenClaw plugin adapter for SkillPilot

Routes agent skills before LLM inference, reducing tokens and improving accuracy.

## Installation

```bash
pnpm add @realtapel/skillpilot-openclaw
```

## Usage

```typescript
import { createOpenClawPlugin } from '@realtapel/skillpilot-openclaw';

export default createOpenClawPlugin();
```
